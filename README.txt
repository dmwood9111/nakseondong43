낙선동 4·3성 QR 안내 페이지 — 공통 메뉴 관리 버전

1. index.html 및 01~08 HTML과 menu.js를 반드시 같은 폴더에 업로드하세요.
2. 메뉴 추가/수정/순서 변경은 menu.js의 window.MENU_ITEMS 배열만 수정하세요.
3. href는 실제 HTML 파일명과 일치해야 합니다. 예: 09_new.html
4. names의 ko/en/zh/ja는 한국어/영어/중국어/일본어 메뉴 이름입니다.
5. 메뉴 항목 순서가 메인 목차, 하단 메뉴 번호, 상세 페이지 이전/다음 링크에 자동 반영됩니다.
6. 새 항목을 추가할 경우 해당 HTML 페이지도 만들어서 업로드해야 합니다.
7. 메인 본문과 상세 페이지 본문 번역은 각각의 HTML 안에 있으므로 메뉴명과 별도로 관리됩니다.
8. 호스팅 서버에 전체 파일을 함께 업로드하세요. PHP 등의 서버측 인클루드 기능은 필요하지 않습니다.
